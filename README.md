   # Portfolio CRUD: Laravel + Inertia.js + React

   IT ELEC01 Midterm Laboratory Activity. Dynamic section: Projects (create, read, update, delete with validation).

   ## Setup
   1. composer install
   2. npm install
   3. copy .env.example to .env
   4. php artisan key:generate
   5. php artisan migrate
   6. php artisan storage:link
   7. npm run dev (in one terminal)
   8. php artisan serve (in another terminal)
   9. Open http://127.0.0.1:8000 (portfolio) and http://127.0.0.1:8000/projects (admin)
